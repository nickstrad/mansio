# compiler

How mansio turns a logical plan or a schema into SQL, and which process runs the SQL. Code: `core/plan.ts`,
`core/compile/` (`dialect.ts`, `select.ts`, `ddl.ts`, `write.ts`, `decode.ts`). Everything there is pure:
nothing throws, and failures come back as a `CompileError`, `SchemaError` or `DecodeError` in an `Either`.

Callers: `platform/document_reader.ts` (queries, SQLite dialect), `platform/sqlite.ts` (DDL, writes, reads
inside mutations) and `platform/duckdb.ts` (DuckDB dialect, reader child). Snapshot of real output:
`core/compile/GENERATED_SQL.txt`, regenerated by `deno task explain`.

Probe script:
`deno run --config deno.json agent-work/work-scripts/deno/compile-plan-probe.ts [walk|table|variants|failures]`
runs the compiler on sample plans and prints the output these entries quote. Rerun it after compiler changes.
